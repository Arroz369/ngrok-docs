# MAIK8I - Assistente Digital Inteligente

O Maik8i não é apenas um chatbot — é um sistema operacional pessoal baseado na nuvem do Google. Ele observa seus dados, aprende padrões, toma decisões contextuais e executa ações sob seu controle total.

## Funcionalidades
- **Análise Inteligente:** Processa planilhas, emails e agenda com Gemini AI.
- **Decisões Contextuais:** Sugere ações baseadas em análise de dados.
- **Execução Controlada:** Todas as ações requerem sua aprovação.
- **100% Serverless:** Zero manutenção, escala automaticamente.

## Estrutura do Projeto
- `functions/`: Código das Cloud Functions (Python).
- `config/`: Regras do Firestore e configurações.
- `scripts/`: Automação de setup e deploy.
- `docs/`: Documentação técnica.
